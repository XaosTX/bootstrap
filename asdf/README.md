# asdf

`plugins.txt` lists the core plugins (`name [url]`), installed by `steps/common/40_asdf.sh`.
Node.js (latest LTS) is the only core plugin for now.

Other plugins from codeangler's bootstrap (`tools/asdf/asdf-*.sh`, and its `dot-tool-versions`) are not ported yet. Each needs its plugin name and version checked before it's added here.
